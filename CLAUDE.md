# Design rules (from Layo, apply to all work on this site)

- Never use a solid left border (or an inset left stripe) as an accent: not on alerts, error or success messages, callouts, quotes, list items or active states. Use a fully outlined tinted box, a background tint, or a leading icon instead.
- No decorative green "live" or status dots next to text (locations, current roles, project cards).
- No floating cursor followers or pointer-tracking tilt on cards and images.
